# NLP-programs
This repository conatins the python programs for Unit 1 of Natural Language Processing (NLP).

## program 1 - Tokenization of Sentences and Words using NLTK and spaCy
This program demonstrates tokenization using NLTK and spaCy.
Tokenization is the process of breaking text into smaller units such as sentences and words.

## program 2 - Stemming and Lemmatization on Sample Text
This program demonstrates stemming and lemmatization on sample words using NLTK.
Stemming means reducing a word to its root form by removing prefixes and suffixes.
Lemmatization converts a word into its meaningful form or dictionary form.

## program 3 - Stop-word Removal from a Document
This program removes common English stop words from a document using NLTK.
Examples of stop words include "the", "is", "and", "of","in", etc.

## program 4 - Part-of-Speech (POS) Tagging of a Given Sentence
This program performs Part-of-Speech(POS) tagging on a given sentence using the NLTK library.
POS tagging is the process of assigning tags to each word in a sentence based on its meaning and context. The program first tokenizes the sentence into individual words and then assigns a POS tag to each word. The program can identify different grammatical categories such as:
- Noun (NN)
- Verb (VB)
- Adjective (JJ)
- Adverb (RB)
- Pronoun (PRP)
- Preposition (IN)
- Determiner (DT)
Library Used : NLTK

## program 5 - Parsing and Chunking using RegEx and spaCy
This program demonstrates parsing and chunking using Regular expressions (RegEx) and spaCy.
Parsing is the process of analzing the grammatical structure of a sentence and identifying the relationships between different words. It helps in understanding how words are connected within a sentence.
Chunking is the process of grouping related words together to form meaningful phrases such as noun phrases.
Libraries used: spaCy and RegEx

## program 6 - Named Entity Recognition (NER) using spaCy
This program performs Named Entity Recognition (NER) using the spaCy library.
NER is a NLP technique uesd to identify and classify important named entities present in a text. It helps computers understand whether a particular word or group of words represents a person, organization, location, date, or another type of entity.
Common entity types include:
PERSON – Name of a person
ORG – Organization or company
GPE – Geographical location
DATE – Date or time
MONEY – Monetary value
EVENT – Event
